# NS Nekretnine

Real-estate platform for **NS Business Consulting** (Novi Sad) — "Most koji spaja ljude i prilike."

Design language: **Editorial Navy & Bridge Gold** — deep navy `#061A30`, restrained bridge gold
`#B08D3F`, Fraunces display serif over Inter, architectural grid, shallow navy-tinted shadows.

## Stack

- TanStack Start (Vite) · React 19 · TypeScript strict
- TanStack Router (file-based, URL-synced filters) · TanStack Query
- Tailwind CSS v4 (`@theme` tokens in `src/styles.css`)
- Radix primitives · lucide-react icons · Bun

## Getting started

```bash
bun install
bun run dev         # http://localhost:3000
```

## Commands

| Command | Purpose |
| --- | --- |
| `bun run dev` | Dev server on :3000 |
| `bun run build` | Production build |
| `bun run start` | Serve production build |
| `bun run typecheck` | `tsc --noEmit` |
| `bun run lint` | ESLint |
| `bun run format` | Prettier |
